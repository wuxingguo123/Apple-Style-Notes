# 第一章 线性表

> 本章涵盖顺序表、链表等线性数据结构的基本概念与操作。

## 线性表的定义

线性表是 $n$ 个**相同类型**数据元素的有限序列，记作 $(a_1, a_2, \ldots, a_n)$。

- **顺序存储**：数组实现，支持随机访问，插入/删除 O(n)
- **链式存储**：指针链接，插入/删除 O(1)，但不支持随机访问

## 顺序表

顺序表用一段**连续内存**存储元素。

| 操作 | 时间复杂度 |
|------|-----------|
| 访问 | O(1) |
| 插入 | O(n) |
| 删除 | O(n) |
| 查找 | O(n) |

## 单链表

每个节点包含**数据域**和**指针域**，通过指针将各节点串联。

```c
typedef struct LNode {
    ElemType data;
    struct LNode *next;
} LNode, *LinkList;
```

## 双链表

节点同时持有 `prev` 和 `next` 两个指针，支持双向遍历。

## 循环链表

尾节点的 `next` 指向头节点，构成环形结构。
